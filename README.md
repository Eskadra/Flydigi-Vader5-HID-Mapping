# Flydigi Vader 5 Pro — исследование HID и карта кнопок для Arduino

## Назначение

Этот репозиторий — **вспомогательный инструмент исследования HID-протокола геймпада Flydigi Vader 5 Pro** на компьютере (macOS). Его основная задача — получить и проверить файл **`flydigi_mapping.json`**, который затем используется как исходные данные при разработке отдельной программы (прошивки) для Arduino/ESP32-S3.

**Это не готовая прошивка Arduino, не Xbox-адаптер и не программа, которая сама подключает геймпад к Xbox.**

## Состав

| Путь | Назначение |
| --- | --- |
| `flydigi_test.py` | Python-тест HID: открывает интерфейс устройства, выполняет инициализацию, предлагает по очереди нажимать кнопки и сохраняет результаты |
| `flydigi_mapping.json` | Полученная карта кнопок и примеры HID-отчётов при нажатии и отпускании |
| `ControlLab/` | Исходный экспериментальный проект macOS для работы с Flydigi; используется как источник контекста по протоколу |
| `ControlLab/README_EN.md` | Оригинальная документация ControlLab (английский язык) |

## Оборудование и протокол

- Устройство: **Flydigi Vader 5 Pro**.
- USB VID: **`0x37D7`**.
- USB PID: **`0x2401`**.
- Используемый Python-тестом HID usage page: **`0xFFA0`**, usage: **`0x01`**.
- Искомый игровой отчёт начинается с **`5A A5 EF`**; в примерах из имеющегося JSON отчёты имеют длину 32 байта.
- В поле `byte` записан **индекс байта с нуля**, а `mask` — битовая маска кнопки.

Эти значения относятся к исследованному интерфейсу и режиму устройства; при другой версии прошивки или способе подключения требуется перепроверка.

## Запуск теста на macOS

Нужны Python 3 и библиотека `hid` (Python-модуль HIDAPI). Подключите приёмник Flydigi и убедитесь, что контроллер обнаруживается.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install hidapi
python3 flydigi_test.py
```

Тест открывает HID-интерфейс, отправляет команды инициализации, ожидает отчёты `5A A5 EF`, последовательно предлагает нажать/отпустить кнопки и сохраняет результаты в `flydigi_mapping.json` **в текущем рабочем каталоге**. При ошибке или прерывании скрипт также сохраняет уже собранные результаты.

> Команды инициализации отправляются непосредственно устройству. Не запускайте тест одновременно с другой программой, использующей тот же интерфейс. Работа зависит от доступности HID-интерфейса и режима контроллера.

## Формат flydigi_mapping.json

```json
{
  "device": "Flydigi Vader 5 Pro",
  "vid": "0x37D7",
  "pid": "0x2401",
  "timestamp": "2026-10-21T22:49:21.116760",
  "results": [
    {
      "button": "A",
      "byte": 11,
      "mask": "0x10",
      "pressed_report": "5a a5 ef ...",
      "released_report": "5a a5 ef ..."
    }
  ]
}
```

Поля `pressed_report` и `released_report` — диагностические снимки исходных HID-пакетов. Их нельзя трактовать как фиксированный шаблон целого пакета: значения стиков и прочие поля могут изменяться между чтениями.

## Пример распознавания кнопки

Для **A** в имеющемся файле зафиксированы `byte = 11`, `mask = 0x10`; для **B** — `byte = 11`, `mask = 0x20`.

```cpp
// Пример логики декодирования на Arduino/ESP32-S3.
// data — уже полученный HID-отчёт, len — его длина.
bool isA(const uint8_t* data, size_t len) {
    return len > 11 &&
           data[0] == 0x5A && data[1] == 0xA5 && data[2] == 0xEF &&
           (data[11] & 0x10) != 0;
}
```

Это только декодирование уже полученного отчёта. Для настоящей Arduino-прошивки отдельно необходимо реализовать USB-host/HID-подключение, выбор нужного интерфейса, инициализацию устройства и чтение отчётов. Для использования с Xbox потребуется отдельная, совместимая с консолью реализация выходного устройства/протокола: один `flydigi_mapping.json` этого не обеспечивает.

## Как использовать результат при разработке Arduino

1. Получить `flydigi_mapping.json` на компьютере с подключённым Flydigi Vader 5 Pro.
2. Проверить корректность `byte` и `mask` для необходимых кнопок.
3. Перенести таблицу байтов и масок в проект прошивки (вручную или генератором заголовочного файла).
4. На Arduino/ESP32-S3 принимать реальные HID-отчёты от USB-приёмника и преобразовывать их в состояния кнопок.
5. Отдельно реализовать обработку стиков, курков, вибрации и целевой выходной интерфейс — наличие кнопочной карты не означает, что эти функции уже исследованы или реализованы.

## Проверка результатов

```bash
python3 -m json.tool flydigi_mapping.json > /dev/null && echo "JSON корректен"
```

В имеющемся файле есть результаты для кнопок A, B, X, Y, LB, RB, BACK, START, L3, R3, C, Z, M1–M4, HOME, FN, LM и RM. Структура JSON содержит отображение кнопок и снимки пакетов, но не является полной спецификацией всего HID-протокола.
